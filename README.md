# BMCE Capital — Super App · Écran d'accueil (Gestion Privée)

Maquette HTML de l'écran d'accueil du palier Premium de la Super App BMCE Capital.

- `index.html` — mockup iPhone 15 Pro (393 × 852 pt) : contenu scrollable, navigation fixe en bas, Dynamic Island.
- `screen.html` — l'écran seul, sans habillage (nav fixe en bas, scroll de page), pour intégration / test sur mobile.
- `figma-export.svg` — export vectoriel à glisser dans Figma (calques éditables).

## Design
- Palette : navy `#00294D` (marque), or `#C9A25A / #E4CB92` (premium), teal `#37A7B8` (essentiels), dark mode.
- Typographie : Plus Jakarta Sans (Google Fonts).
- Hiérarchie : Stories → Patrimoine → **Mes applications** (Bourse en vedette + Titres, Gestion, FX Direct, Research) → **Services Premium** (Conciergerie, Pharmacie de garde, Art de vivre).
- Navigation : Accueil · Patrimoine · **Conseiller** (centre) · Services · Profil.

Fichiers autonomes : logo, photos et styles sont embarqués (data URI), aucune dépendance hors Google Fonts.
Données affichées illustratives.
